# Roadmap

The bootstrap pass inventories this repository and emits artifact atoms plus three deterministic perspectives.

The next pass adds reference extraction, Git history, commit/author provenance, bounded recursive frontier expansion, and a graph schema.

After that come pluggable public-source adapters, semantic embeddings, creator-claimed identity roots, signed invention atoms, resonance fingerprints, temporal lineage, disagreement preservation, and a graph UI.

The system is deliberately useful without external API keys. Network enrichers remain optional adapters.
